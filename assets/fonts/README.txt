ORNAMENT FONTS
Put the font files here, named exactly like this (one format is enough;
.woff2 is best for the web, .otf/.ttf also work):

  autoctona.otf   -> Autóctona Dingbats (Mauricio Javier Franco)
                     used for section icons and the dividers between sections
  desprecio.otf   -> Desprecio (Carlos Carpintero / Pulpa Roja)
                     used for the row of figures above your portrait

Then open assets/style.css, section "WHICH ORNAMENT GOES WHERE", and set
which letter of each font draws which figure (check in Font Book).

Make sure the font license allows web use (embedding on a website).
