CONFERENCE GALLERY
- One folder per conference, named YYYY-MM_short-name (newest is shown first).
- index.md = title, date, place, role, optional link + your reflection below.
- Drop photos (.jpg/.png) in the folder. The caption comes from the file name:
  02_poster-session-with-julius.jpg -> "Poster session with julius".
- iPhone .HEIC photos: export as JPG first (Photos app > File > Export).
- Photos can also go in a subfolder (e.g. pictures/).
- Spanish captions: add captions.es.txt next to the photos, one line per photo:
  07_lake-shore.jpg: La orilla del lago
