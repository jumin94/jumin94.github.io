ACADEMIC JOURNEY
- One folder per place/stage; the number at the start sets the order (01_, 02_, ...).
- index.md = place, flag emoji, years, role + your story below.
- Drop photos in the same folder; they become a small gallery.
  The caption comes from the file name: 01_first-day-at-the-institute.jpg -> "First day at the institute".
- To add a stage between two others, e.g. 05 and 06, name it 05b_new-place.
